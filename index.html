ICAO Chart Reference SOP Guide

About ICAO Annex 4: Annex 4 to the Convention on International Civil Aviation governs Aeronautical Charts used in worldwide civil aviation navigation. Standardized colors, lines, and shapes ensure cross-border flight safety.

Keyboard Shortcuts:

  • Space / Click : Flip Card
  • ← / → Arrow : Prev / Next
  • Key 'M' : Toggle Mastery
  • Key 'S' : Shuffle Cards

Standard Color Conventions:

Blue/Cyan: Controlled airspaces, navaids, rivers, water.
Magenta: Uncontrolled airspaces, special zones, hazards.
Amber/Brown: Terrain contours, elevation highlights.
Green: Airports with visual lighting / vegetated areas.
